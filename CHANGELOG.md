# Changelog

Versions are named `X.Y.Z-forever`: `0.x` while in beta.

## 0.1.0-forever (beta, unreleased)

### Added
- Fade: the tracker fades out when you're not using it, and comes back on mouse over, when an objective changes, and in Edit Mode (`Fade.lua`).
- Glass look: no game header bars or panel background, the Glass fading background, a chosen font and gold section titles (`Skin.lua`, `Background.lua`).
- Options page (`/gft`) and settings in the Objective Tracker's Edit Mode entry (`Options.lua`, `EditMode.lua`).
